# Achados e Perdidos

Projeto estático pronto para GitHub e Vercel.

## Páginas
- `index.html` — entrada principal
- `Menu/menu.html` — página inicial
- `Login/login.html` — login
- `Categoria/index.html` — itens
- `Sobre/sobre.html` — como usar

## Observação
Os caminhos de CSS, JavaScript e imagens foram corrigidos para respeitar maiúsculas/minúsculas em servidores Linux, como os usados pela Vercel.

## Vercel
Importe o repositório normalmente. Não é necessário build command para este projeto estático.

## GitHub
Envie o conteúdo desta pasta para a raiz do repositório.
